# klyvin

منصة بتسمح لأصحاب البيزنيس والتجار يفتحوا **متجر إلكتروني** خاص بيهم بنفسهم، من غير برمجة. التاجر يسجل، ويظبط متجره من لوحة تحكم، ويلاقي متجره شغال على رابط فرعي (subdomain) تابع للمنصة.

> **الحالة الحالية:** مرحلة التخطيط. المستودع فيه التوثيق بس، لسه مفيش كود.

## التوثيق

| الملف | فيه إيه |
|---|---|
| [`docs/PRD.md`](docs/PRD.md) | وصف المنتج: الصفحات، لوحة التحكم، الصلاحيات، الدفع، الشحن، الباقات |
| [`docs/TECH-DECISION.md`](docs/TECH-DECISION.md) | ليه اخترنا Astro + React، والبدائل اللي اترفضت |
| [`docs/STACK.md`](docs/STACK.md) | الميزانية والأدوات المجانية (الاستضافة، قاعدة البيانات، تخزين الملفات) وتكلفتها |

## الأدوات (ملخص)

- **الإطار:** Astro + React
- **الاستضافة وقاعدة البيانات وتخزين الصور والملفات:** Cloudflare (Workers وD1 وR2)
- **الكود:** GitHub (مستودع خاص)
- **الميزانية الشهرية في البداية:** صفر

## قواعد مهمة

1. **ممنوع رفع أي سر على Git:** مفاتيح، كلمات سر، توكنات، ملفات `.env`. ملف `.gitignore` بيمنع الشائع منها، بس مش بيغني عن الانتباه.
2. **بيانات المتاجر الحقيقية والصور اللي بيرفعها التجار مش بتتحفظ هنا.** مكانها قاعدة البيانات ومخزن الملفات.
3. **العزل بين المتاجر شرط حرج:** متجر مايشوفش بيانات متجر تاني أبداً.
